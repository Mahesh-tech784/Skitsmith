# How to Select and Use a Chatbot in SkitSmith

## Navigation Flow

### Step 1: View Your Chatbots
After login, you'll be automatically redirected to the **"My Chatbots"** page where you can see all available chatbots in a table.

**Location:** 
- Click **"My Chatbots"** in the header navigation
- Or go to: `/default/bot-list`

### Step 2: Choose a Chatbot
On the **"My Chatbots"** page, you'll see a table with:
- Bot Name
- Description
- Created Date
- Action buttons

Each chatbot row has two action buttons:
- **Upload Doc** - Upload files for the chatbot to learn from
- **Chat** - Start chatting with the selected chatbot

### Step 3: Start Chatting
Click the **"Chat"** button to open the chat interface for that specific chatbot.

The ChatPage header now includes:
- ← **Back to Chatbots** button - Switch to a different chatbot
- ⤓ **PDF** button - Download the chat as a PDF

## Navigation Menu (Header)

You can quickly navigate between sections using the header menu:
1. **My Chatbots** - View and manage your chatbots
2. **Chat** - Access the current chat session
3. **Sign Out** - Logout from the application

## Features After Selecting a Chatbot

Once you've selected a chatbot and are in the Chat page:

1. **Send Messages** - Type your message and click "Send" or press Enter
2. **View Chat History** - All messages are displayed in the chat window
3. **Switch Chatbots** - Click "Back to Chatbots" to select a different bot
4. **Export as PDF** - Click "PDF" to download the current conversation
5. **Upload Documents** - Go to "My Chatbots" and click "Upload Doc" to add training documents

## Troubleshooting

**Q: I don't see the "My Chatbots" page after login**
- A: The app should automatically redirect you. If not, click "My Chatbots" in the header navigation.

**Q: I see an error when trying to chat**
- Make sure you've selected a chatbot from the "My Chatbots" page
- Check that the chatbot has been properly created and has a namespace_id
- Ensure you have uploaded at least one document for the chatbot to reference

**Q: I want to switch to a different chatbot**
- A: Click the "← Back to Chatbots" button in the Chat page header to return to the chatbot selection page.
